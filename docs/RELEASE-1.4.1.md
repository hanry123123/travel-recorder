# 旅迹 1.4.1 · iOS / Android

## 下载

- `TravelRecorder-1.4.1.ipa`：iOS14及以上，使用TrollStore直接更新。
- `TravelRecorder-1.4.1.apk`：Android8.0及以上，直接安装或更新。
- `TravelRecorder-1.4.1-source.tar.gz`：本次公开源码。
- `VERIFICATION.json`、`SHA256SUMS`：验证范围及附件校验值。

请直接覆盖更新，不卸载旧版，以保留本机旅程。两个平台目前不自动同步数据。

## 改动

- iOS圆形地图按钮改为同一控件直接绘制圆面和图标，取消额外栅格化；简化地图裁剪并调整接缝。
- 两端记录、回忆及详情分享入口只保留图标，保留原点击行为和读屏名称。
- 相比此前公开的1.2.0，包含动态路线重现、连续平滑镜头、照片加载修订、收藏和图片/视频分享、启动后台加载，以及Android原生版本。

## 验证边界

1.4.1：iOS原生构建、146项IPA审计、宿主ldid签名回归、23项现有Mac Catalyst启动/镜头/照片/分享检查通过；浅深色2x/3x生产按钮预览已检查。Android签名构建、API30模拟器保留数据覆盖升级、无文字分享图标点击进入图片/视频选择通过，安装包与发布文件SHA一致。

本次未重跑未修改的1.4.0核心/Android服务全套，也未完成实体手机验收。手机正常全屏下的黑圈和细线是否消失仍需确认。系统截图无法捕捉时可用另一设备拍屏。实际锁屏定位、相机返回时序、地图网络及微信接收也不由电脑测试证明。
